# 嘸蝦米輸入法網頁版 — 功能說明

> 原 Python + Win32 Hook 版本移植，鍵盤點擊與實體鍵入共用同一套組字核心。
> 預設為「正常組字」，打 `,,ai` 可開啟**兩字詞（以上）自動組合、無限碼長**功能。

## 基本使用

點一下編輯區聚焦後，直接用實體鍵盤打字根，或用滑鼠點擊下方虛擬鍵盤，兩者行為完全相同。輸入字根後，游標右下角會即時彈出淡黃色的浮動視窗，顯示目前打的拆碼字根與候選字清單。

## 浮動視窗

浮動視窗會出現在游標右下角、離游標很近的地方，固定為淡黃色底、黑色字，字級與編輯區同步縮放。依情況顯示：

- **打字根組字時**：顯示目前打的拆碼字根，下方接著列出候選字（含選字用的編號）。
- **候選字**：與拆碼字根一起顯示在同一個浮動視窗中。
- **`,,ai` 組合模式累積中**：額外顯示目前已選出、還沒送出的組字進度（詳見下方）。
- **選字送出後**（同音字或萬用字元模式的最終結果）：直列顯示該字所有標準拆碼，不含任何提示文字。

## 選字方式

候選字清單以 `0`～`9` 編號，`0` 為第 1 個候選，`9` 為第 10 個候選。

- 按對應**數字鍵**（`0`～`9`）直接選字。
- 按**空白鍵**選候選清單第一個字（等同 `0`）。
- 候選字過多可翻頁：`↑` / `↓` 切換上一頁／下一頁。
- 符合慣用字尾 `'` 且候選唯一時，會自動直接送出。

## 兩字詞（以上）自動組合，無限碼長（`,,ai`）

**預設關閉**：正常組字，選字後立刻上字，跟一般輸入法沒有兩樣。打前綴 `,,ai` 可開啟這項功能，離開方式與其他特殊模式相同，共用 `,,t`（離開後即恢復成「正常組字」）。左上角印章開啟後顯示「詞」。

### 運作方式

開啟後，一般模式（非快打／同音字／萬用字元／注音／台／簡／日等專用模式）下選字時，選出來的字**不會立刻上字**，而是先累積進暫存區——**不限字數，想連續打幾個字都可以**。直到使用者連續按**兩個空白**（沒有再打任何字根），才代表這個詞打完了，開始結算：

系統會把暫存區裡每個位置當初的候選字排列組合，去詞庫裡比對「剛好打了幾個字」的詞：

| 比對結果 | 動作 |
|---|---|
| 剛好一個相符的詞 | 直接送出那個詞（不一定等於使用者原本各自選的那幾個字，例如各自選到「中」「華」「民」「國」的候選過程中湊出「中華民國」）。 |
| 一個以上相符 | 全部列出來，讓使用者用一般選字方式（數字鍵／快選鍵／空白＝第一個／`↑↓` 翻頁）自己挑一個。 |
| 完全比對不到 | 就照使用者原本各自選的那幾個字，依序送出。 |
| 只打了一個字就按兩個空白結束 | 例外處理，不比對詞庫，直接送出那個字。 |

> 要確認內建詞庫（group7）或外部詞庫（`.box`）有這個詞才能打出，注意外部詞庫要手動匯入（見〈[詞庫](#詞庫)〉）。

快打／同音字／萬用字元／注音／台／簡／日／符號（`w0`～`w9`）／拆碼加 `'` 直查詞庫等模式的選字，不受此開關影響，一律維持原本行為：選完立刻上字。

## 連續兩個空白（僅在自動組合開啟時生效）

選字剛送出、字根已清空、暫存區還有累積的字時，若使用者馬上又按一次空白鍵（沒有再打任何字根），代表「這個詞打完了」，交給上面的比對規則結算並送出結果。

- 按 **`Backspace`** 可收回暫存區裡**最後一個**還沒送出的字（不影響前面已經累積好的字）。
- 切換模式、按 **`Esc`**，或進入任何特殊前綴模式前，暫存中的字會直接依序被送出，不會憑空消失。

## 快速選字鍵

組字中若接下來按下列鍵已經查不到更長字根，會被當成候選字快選鍵；否則視為一般字根繼續組字。選到後還要再按一次空白鍵或 `0` 才會真正送出。（同音字第二階段、`,,ai` 挑詞清單階段，也可直接用這些鍵快選。）

| 按鍵 | 對應候選（編號） |
|---|---|
| `v` | 候選 1 |
| `r` | 候選 2 |
| `s` | 候選 3 |
| `f` | 候選 4 |
| `w` | 候選 5 |
| `l` | 候選 6 |
| `c` | 候選 7 |
| `b` | 候選 8 |
| `k` | 候選 9 |

## 萬用字元模式

- `[` 或 `*`：代表多個未知拆碼。例：`r[o` → 列出「蒼／菇／蘑」等。
- `]` 或 `?`：代表剛好多一個未知拆碼。例：`r]o` → 列出「苦／苔／茄」等。
- 選字送出後，游標處會彈出浮動視窗，直列顯示該字所有標準拆碼。

## 同音字模式

1. 按 `'`（單引號）進入同音字模式，開始打字根選「底字」。
2. 打字根選出一個「底字」（例：`gqe` → 空白鍵選「重」）。
3. 系統自動列出同音字群（例：「重／種／仲」），可用數字鍵、空白鍵，或 `v r s f w l c b k` 快選鍵選字。
4. 送出的同時，游標處會彈出浮動視窗，直列顯示該字所有標準拆碼。

## 注音模式

跟萬用字元、同音字模式一樣，是**一次性**的功能：打 `';`（單引號接分號）進入，用標準注音鍵盤打一個注音音節、選出一個字之後，會**自動退回一般模式**，不用再打 `,,t` 離開。

- 按 `';`（單引號接分號）進入注音模式，印章顯示「注」。
- 用標準注音鍵盤打注音：數字鍵、`, . / - ;` 都改成注音符號／聲調鍵用（空白鍵＝一聲），這段期間不能拿來選字。
- 音節打完（按下任一聲調鍵，含空白）出現候選字之後，才能用空白鍵、數字鍵，或 `v r s f w l c b k` 快選鍵照常選字。
- 選字送出後，游標處會彈出浮動視窗，直列顯示該字所有標準拆碼，同時自動離開注音模式、回到一般模式。

> `'` 同時是同音字模式的觸發鍵，也是注音模式（`';`）的前綴，打完 `'` 會先暫停判定：打 `;` 確認進入注音模式；打其他任何鍵（含空白鍵）則視同確認進入同音字模式，該鍵會在同音字模式下重新處理一次。

## 特殊前綴模式一覽

組字中打出下列前綴，會切換到對應的模式，並**持續生效**（不是一次性的），直到打 `,,t` 才會離開、切換回原本的打法。切換時，左上角印章會即時顯示目前模式。

| 前綴 | 模式 | 印章 | 說明 |
|---|---|---|---|
| `,,ct` | 打繁出簡 | 台 | 之後查詢只查繁轉簡字庫。 |
| `,,c` | 簡體 | 簡 | 之後查詢只查簡體字庫。 |
| `,,j` | 日文 | 日 | 之後查詢只查日文字庫。 |
| `,,sp` | 快打模式 | 快 | 正常拆碼、正常選字；選字送出後，若該字有一種以上的標準拆碼，會另外用浮動視窗顯示其中最短的一種拆碼，只有一種拆碼則不特別顯示、直接上字。 |
| `,,ai` | 兩字詞（以上）自動組合，無限碼長 | 詞 | 開啟後一般模式選字會先暫存湊詞、支援連續兩個空白結算組合，詳見〈[兩字詞（以上）自動組合，無限碼長](#兩字詞以上自動組合無限碼長ai)〉。**預設關閉**。 |
| `,,t` | 離開 | 中／英 | 離開上述任一模式，切換回原本的打法。 |

> `,,c` 剛好是 `,,ct` 的前三碼，打到 `,,c` 時會先暫停判定：按**空白鍵**確認進入「簡」模式；接著打 `t`（湊成 `,,ct`）則直接進入「台」模式；打其他任何鍵則視同確認進入「簡」模式，該鍵會在新模式下重新處理一次。

## 詞庫

內建少量範例詞（如 `nhwu'` → 「憲法」）。可點工具列「匯入詞庫檔」匯入自己的 `.box` / `.txt` 檔（UTF-8 純文字，每行「拆碼　空白　詞語」），擴充可打出的詞語。

- 匯入的詞庫只存在目前分頁的記憶體中，重新整理頁面後需重新匯入。
- 後綴名（`'`）可加也可不加，若是加上，且只有一個詞，就會直上，不用按空白鍵。
- `,,ai` 自動組合模式比對的，也是同一份詞庫（依詞長分類查詢），匯入新詞庫後對照表會自動重建。

## 中英文與全形／半形

- 切換中文／英文：`F12`、`Ctrl+空白鍵`、單獨點一下 `Ctrl` 鍵，或工具列按鈕。
- 切換全形／半形：`Shift+空白鍵`，或工具列按鈕。

## 版本備註

本檔案對應版本已將 `,,ai` 功能從「僅限兩字詞」升級為**無限碼長版**：不再限制只能湊兩個字才比對詞庫，只要詞庫裡有對應字數的詞，累積打幾個字都能組合，行為與原 Python + Win32 Hook 版本一致。
