# 嘸蝦米輸入法 · 網頁版（顯示注音版）

單一 HTML 檔即可執行的嘸蝦米字根輸入法，由原 Python + Win32 Hook 版本移植而來（作者：史治華）。在瀏覽器的編輯區中用實體鍵盤或虛擬鍵盤打字根組字，支援同音字、注音輸入、顯示注音、快打提示、簡／日／台專用字庫、兩字詞（以上）自動組合、關聯字、萬用字元查詢與外部詞庫匯入。

## 執行方式

- 直接用瀏覽器（Chrome、Edge、Firefox 等）開啟 `Fu-Xia-Mi-Shu-Ru-Fa-Wang-Ye-Ban-_Xian-Shi-Zhu-Yin-Ban.html`，不需安裝、不需伺服器、不需網路。
- 點一下編輯區聚焦後即可開始輸入；打完的文字可用「複製」按鈕貼到其他地方。
- 跨平台：只要有現代瀏覽器即可使用（Windows／macOS／Linux 皆可）。
- 輸入法只在本頁面的編輯區內生效，不會影響系統其他程式。

## 基本輸入

1. 點編輯區後，依拆碼依序按字根鍵，浮動視窗即時顯示字根與候選字。
2. 選字：
   - **數字鍵 `0`～`9`**：`0` 為第 1 個候選，`9` 為第 10 個候選。
   - **空白鍵**：選第 1 個候選（等同 `0`）。
   - **快選字母**：組字中若接下去已查不到更長的字根，下列字母會當成快選鍵；選到後再按空白或 `0` 才真正送出。

     | 按鍵 | v | r | s | f | w | l | c | b | k |
     | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
     | 對應候選編號 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |

3. 翻頁：`↑`／`↓`（每頁 10 個，循環翻頁）。
4. `Backspace`：刪除最後一個字根；沒有字根時刪除編輯區前一個字元。
5. `Esc`：清空目前正在組的字根。
6. 拆碼結尾加 `'` 且候選只有一個時，會自動直接送出。

## 中英文與全形／半形

| 操作 | 功能 |
| --- | --- |

| `Shift+空白` | 切換全形／半形（英文模式下全形會把打出的字元轉為全形） |

## 特殊模式

### 前綴指令（持續生效，打 `,,t` 離開）

| 指令 | 印章 | 功能 |
| --- | --- | --- |
| `,,ct` | 台 | 打繁出簡：查詢只查繁轉簡字庫（group9） |
| `,,c` | 簡 | 簡體模式：查詢只查簡體字庫（group10） |
| `,,j` | 日 | 日文模式：查詢只查日文字庫（group11） |
| `,,sp` | 快 | 快打模式：選字後若該字有更短的標準拆碼，浮動視窗顯示最短拆碼；只有一種拆碼或已是最短則不提示 |
| `,,ph` | 音 | 顯示注音：每選出一個字，浮動視窗列出此字在注音字庫（group8）裡的所有注音 |
| `,,ai` | 詞 | 兩字詞（以上）自動組合，預設關閉（見下方說明） |
| `,,t` | 中 | 離開上述任一模式，回到原本打法 |

`,,c` 剛好是 `,,ct` 的前三碼，打到 `,,c` 時會先暫停判定：

- 按**空白鍵**：確認進入「簡」模式。
- 接著打 `t`：組成 `,,ct`，進入「台」模式。
- 打其他任何鍵：視同進入「簡」模式，該鍵在新模式下重新處理一次。

一次只能處於一種前綴模式；要切換到另一種，請先打 `,,t` 離開。

### 同音字模式（一次性）

1. 按 `'`（單引號）後接英文字母，開始打字根選「底字」。
2. 例：`'` 後打 `gqe`，按空白選「重」。
3. 系統自動列出同音字群（例：「種／仲」，不含底字本身），用數字鍵、空白或 `v r s f w l c b k` 快選。
4. 送出後，浮動視窗直列顯示該字所有標準拆碼，並自動回到一般模式。

### 注音模式（一次性）

1. 打 `';`（單引號接分號）進入，印章顯示「注」，虛擬鍵盤按鍵標籤切換成注音符號。
2. 用標準注音鍵盤打注音：數字鍵與 `, . / - ;` 都當注音符號／聲調鍵（空白＝一聲），這段期間不能用來選字。
3. 音節打完出現候選字後，用空白、數字或快選鍵選字。
4. 送出後浮動視窗顯示該字所有標準拆碼，自動回到一般模式；選字前可打 `,,t` 中途放棄。

`'` 的判定規則：打 `'` 後接 `;` → 注音模式；接英文字母 → 同音字模式；接空白、數字或其他符號 → `'` 視為一般字根，照正常流程處理。

### 萬用字元（一次性）

| 符號 | 意義 | 範例 |
| --- | --- | --- |
| `[` 或 `*` | 多個未知拆碼 | `r[o` → 蒼／菇／蘑 等 |
| `]` 或 `?` | 剛好一個未知拆碼 | `r]o` → 苦／苔／茄 等 |

一般模式下比對一般字根表（group5）；在台／簡／日模式下則比對該模式的字庫。選字送出後，浮動視窗直列顯示該字所有標準拆碼。（範例的實際結果取決於你的字根表內容。）

### 兩字詞（以上）自動組合（`,,ai`）

**預設關閉**，關閉時選字後立刻上字。打 `,,ai` 開啟後：

- 一般模式下每選一個字，先放進暫存區、不立刻上字（不限字數），浮動視窗顯示組字進度。
- 選完最後一個字後再按一次空白結算（若最後一字也是用空白選的，就是連續兩個空白）：
  - 比對到剛好一個詞：直接送出該詞（例：分別選到「中」「華」「民」「國」，湊出「中華民國」）。
  - 比對到多個：全部列出，用一般選字方式挑一個。
  - 比對不到：依序送出原本各自選的字。
  - 只打了一個字：直接送出該字。
- `Backspace` 可收回暫存區最後一個字；切換模式、按 `Esc` 或進入其他前綴模式前，暫存的字會先依序送出，不會消失。
- 快打、同音字、萬用字元、注音、台／簡／日、符號（`w0`～`w9`）、拆碼加 `'` 直查詞庫等選字，不受此開關影響，一律選完立刻上字。
- 詞必須存在於內建詞庫或匯入的 `liu.box` 中才能組出。

### 關聯字

點工具列「關」切換成「聯」即開啟。每送出一個單一中文字，會列出詞庫（group7）中以這個字開頭的詞的後續部分當候選（例：送出「中」後列出「華民國」等）。

- 數字鍵（`0` 為第 1 個）或空白鍵選字，`↑↓` 翻頁。
- `Esc`／`Backspace` 取消，不送出任何字。
- 直接打下一個字的字根，會自動結束關聯字候選。
- 選出的若是單字，會繼續列出它的關聯字，可連續串出更長的詞。

### 符號（w0～w9）

`w` 加數字的兩碼組合輸出符號（例：`w0` → ㄅ／ㄆ／ㄇ），選完立刻上字。

## 詞庫

### 內建字庫

| 字庫 | 用途 |
| --- | --- |
| group5 | 一般字根表（單字），萬用字元比對對象 |
| group6 | `w0`～`w9` 符號表 |
| group7 | 詞庫；匯入的詞庫會併入這裡，自動組合與關聯字都只查這裡 |
| group8 | 注音／同音字反查表 |
| group9 | 打繁出簡（台，`,,ct`） |
| group10 | 簡體（`,,c`） |
| group11 | 日文（`,,j`） |

內建字庫只有少量示範內容（如 `a` → 對、`nhwu'` → 憲法、`ciajoxoh'` → 中華民國），實際可打的字詞取決於你修改的字庫內容與匯入的詞庫檔。

### 匯入詞庫檔

- 點工具列「匯入詞庫檔」，選擇 `.box` 或 `.txt` 檔。
- 格式：UTF-8 純文字，每行「拆碼 空白 詞語」；`#` 開頭為註解，空行略過；拆碼不分大小寫。
- 拆碼後綴 `'` 可加可不加；有加且該碼只有一個詞時，會直接上字不用按空白。
- 匯入後會自動重建快打與自動組合用的索引。
- **匯入的詞庫只存在目前分頁的記憶體中，重新整理頁面後需要重新匯入。**

範例：

```
# 自訂詞庫
nhwu' 憲法
ciajoxoh' 中華民國
```

## 虛擬字根鍵盤

- 點工具列「顯示虛擬鍵盤」開啟，佈局比照實體鍵盤，點擊行為與實體按鍵完全相同。
- 實體鍵盤按下時，對應虛擬按鍵會同步反白。
- 「倚」鍵：顯示目前模式指示字，點擊可切換中文／英文。
- `Ctrl`：點一下直接切換中文／英文。
- `Shift`：黏滯鍵，點一下套用到下一個按鍵後自動還原。
- `Caps`：切換大小寫鎖定；`Tab`、`Enter`、`←`、`→` 直接作用在編輯區。
- 進入注音模式時，按鍵標籤自動換成注音符號，離開後還原。

## 注意事項

- 輸入法只在本頁編輯區內生效，要用在其他程式請按「複製」後貼上（注意複製後編輯區會被清空）。
- 匯入的詞庫不會保存，重新整理頁面需重新匯入；若要永久保存，請直接編輯 HTML 內的字庫資料（group5～group11）。
- 「複製」優先使用瀏覽器剪貼簿 API；若瀏覽器限制（例如以 `file://` 開啟的部分情況），會自動改用備援方式複製。
