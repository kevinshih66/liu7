# 嘸蝦米輸入法 · 網頁版

一個純前端（單一 HTML 檔，內含 CSS／JavaScript，無需安裝、無外部依賴）實作的嘸蝦米輸入法模擬器。可用實體鍵盤打字根，也可用滑鼠點畫面下方的虛擬鍵盤，兩者行為完全相同。

## 快速開始

1. 用瀏覽器開啟 `.html` 檔即可使用，不需安裝、不需連網、不需伺服器。
2. 點一下編輯區使其取得焦點。
3. 直接用實體鍵盤打字根，或用滑鼠點擊下方虛擬鍵盤。
4. 點工具列「功能說明」可隨時在畫面上打開跟本文件內容一致的說明面板。

## 基本使用

輸入字根後，游標右下角會即時彈出淡黃色的浮動視窗，顯示目前打的拆碼字根與候選字清單。

## 浮動視窗

浮動視窗固定為淡黃色底、黑色字，字級與編輯區同步縮放，出現在游標右下角、離游標很近的地方。依情況顯示三種內容：

- **打字根組字時**：顯示目前打的拆碼字根，下方接著列出候選字（含選字用的編號）。
- **候選字**：與拆碼字根一起顯示在同一個浮動視窗中。
- **選字送出後**（同音字或萬用字元模式的最終結果）：直列顯示該字所有標準拆碼，不含任何提示文字。

## 選字方式

候選字清單以 `0`～`9` 編號，`0` 為第 1 個候選，`9` 為第 10 個候選。

- 按對應**數字鍵**（`0`～`9`）直接選字。
- 按**空白鍵**選候選清單第一個字（等同 `0`）。
- 候選字過多可翻頁：`↑`／`↓` 切換上一頁／下一頁。
- 符合慣用字尾 `'` 且候選唯一時，會自動直接送出。

## 兩字詞（以上）自動組合，無限碼長（,,ai）

**預設關閉**：正常組字，選字後立刻上字，跟一般輸入法沒有兩樣。

打前綴 `,,ai` 開啟這項功能，離開方式與其他特殊模式相同，共用 `,,t`（離開後即恢復成「正常組字」）。

開啟後，一般模式（非快打／同音字／萬用字元／注音／台／簡／日等專用模式）下選字時，選出來的字不會立刻上字，而是先累積進暫存區（不限字數，想連續打幾個字都可以），直到使用者連續按**兩個空白**（沒有再打任何字根）才代表這個詞打完了，開始結算：系統會把暫存區裡每個位置當初的候選字排列組合，去詞庫裡比對「剛好打了幾個字」的詞：

- 比對到剛好一個相符的詞：直接送出那個詞（不一定等於使用者原本各自選的那幾個字，例如各自選到「中」「華」「民」「國」的候選過程中湊出「中華民國」）。
- 比對到一個以上：全部列出來，讓使用者用一般選字方式（數字鍵／快選鍵／空白＝第一個／↑↓翻頁）自己挑一個。
- 比對不到：就照使用者原本各自選的那幾個字，依序送出。
- 只打了一個字就按兩個空白結束：不比對詞庫，直接送出那個字。

要確認內建詞庫（group7）或外部詞庫（`.box`）有這個詞才能打出，注意外部詞庫要手動匯入。

快打／同音字／萬用字元／注音／台／簡／日／符號（`w0`～`w9`）／拆碼加 `'` 直查詞庫等模式的選字，不受此開關影響，一律維持原本行為：選完立刻上字。

### 連續兩個空白（僅在自動組合開啟時生效）

選字剛送出、字根已清空、暫存區還有累積的字時，若使用者馬上又按一次空白鍵（沒有再打任何字根），代表「這個詞打完了」，交給上面的比對規則結算並送出結果。

按 `Backspace` 可收回暫存區裡最後一個還沒送出的字（不影響前面已經累積好的字）；切換模式、按 `Esc` 或進入任何特殊前綴模式前，暫存中的字則會直接依序被送出，不會憑空消失。

## 快速選字鍵

組字中若接下來按下列鍵已經查不到更長字根，會被當成候選字快選鍵；否則視為一般字根繼續組字。選到後還要再按一次空白鍵或 `0` 才會真正送出。

| 按鍵 | 對應候選（編號） |
| --- | --- |
| `v` | 候選 1 |
| `r` | 候選 2 |
| `s` | 候選 3 |
| `f` | 候選 4 |
| `w` | 候選 5 |
| `l` | 候選 6 |
| `c` | 候選 7 |
| `b` | 候選 8 |
| `k` | 候選 9 |

## 萬用字元模式

- `[` 或 `*`：代表多個未知拆碼。例：`r[o` → 列出「蒼／菇／蘑」等。
- `]` 或 `?`：代表剛好多一個未知拆碼。例：`r]o` → 列出「苦／苔／茄」等。
- 選字送出後，游標處會彈出浮動視窗，直列顯示該字所有標準拆碼。

## 同音字模式

1. 按 `'`（單引號）進入同音字模式，開始打字根選「底字」。
2. 打字根選出一個「底字」（例：`gqe` → 空白鍵選「重」）。
3. 系統自動列出同音字群（例：「重／種／仲」），可用數字鍵、空白鍵，或 `v r s f w l c b k` 快選鍵選字。
4. 送出的同時，游標處會彈出浮動視窗，直列顯示該字所有標準拆碼。

`'` 同時是同音字模式的觸發鍵，也是注音模式（`';`）的前綴，具有歧義。打完 `'` 後先暫停判定，依下一鍵決定去向：

| 下一鍵 | 行為 |
| --- | --- |
| `;` | 確認進入**注音模式**（印章「注」） |
| 英文字母 `a`～`z` | 確認進入**同音字模式**，該鍵會在同音字模式下重新處理一次 |
| 空白鍵／數字鍵／其他符號 | **不攔截**，交給後面一般流程處理（例如單獨打一個 `'` 再按空白鍵，會正常選出 `'` 這個字根自己的候選字，不會被誤判成同音字模式） |

> `'` 本身也是一個合法字根，只有在下一鍵明確是英文字母時才會判定為「要繼續打字根選同音字底字」，避免打「`'` ＋ 其他非英文字母字根」組成的正常複合字根碼時被誤判。

## 注音模式

跟萬用字元、同音字模式一樣，是**一次性**的功能：打 `';`（單引號接分號）進入，用標準注音鍵盤打一個注音音節、選出一個字之後，會**自動退回一般模式**，不用再打 `,,t` 離開。

- 按 `';`（單引號接分號）進入注音模式，印章顯示「注」。
- 用標準注音鍵盤打注音：數字鍵、`, . / - ;` 都改成注音符號／聲調鍵用（空白鍵＝一聲），這段期間不能拿來選字。
- 音節打完（按下任一聲調鍵，含空白）出現候選字之後，才能用空白鍵、數字鍵，或 `v r s f w l c b k` 快選鍵照常選字。
- 選字送出後，游標處會彈出浮動視窗，直列顯示該字所有標準拆碼，同時自動離開注音模式、回到一般模式。

| `5` | ㄓ | `t` | ㄔ | `g` | ㄕ | `b` | ㄖ |

## 特殊前綴模式

組字中打出下列前綴，會切換到對應的模式，並**持續生效**（不是一次性的），直到打 `,,t` 才會離開、切換回原本的打法。切換時，左上角印章會即時顯示目前模式。

| 前綴 | 模式 | 印章 |
| --- | --- | --- |
| `,,ct` | 打繁出簡模式，之後查詢只查繁轉簡字庫 | 台 |
| `,,c` | 簡體模式，之後查詢只查簡體字庫 | 簡 |
| `,,j` | 日文模式，之後查詢只查日文字庫 | 日 |
| `,,sp` | 快打模式：正常拆碼、正常選字；選字送出後，若該字有一種以上的標準拆碼，會另外用浮動視窗顯示其中最短的一種拆碼，只有一種拆碼則不特別顯示、直接上字 | 快 |
| `,,ai` | 兩字詞（以上）自動組合模式，無限碼長，詳見上方章節。**預設關閉** | 詞 |
| `,,t` | 離開上述任一模式，切換回原本的打法 | 中／英 |

`,,c` 剛好是 `,,ct` 的前三碼，打到 `,,c` 時會先暫停判定：

- 按**空白鍵**確認進入「簡」模式；
- 接著打 `t`（湊成 `,,ct`）則直接進入「台」模式；
- 打其他任何鍵則視同確認進入「簡」模式，該鍵會在新模式下重新處理一次。

## 詞庫與匯入

內建少量範例詞（如 `nhwu'` → 「憲法」）。可點工具列「匯入詞庫檔」匯入自己的 `.box`／`.txt` 檔（UTF-8 純文字，每行「拆碼　空白　詞語」），擴充可打出的詞語。

- 匯入的詞庫只存在目前分頁的記憶體中，**重新整理頁面後需重新匯入**。
- 後綴 `'` 可加可不加，若加上且只有一個詞，就會直接上字，不用按空白鍵。

## 中英文與全形／半形

- 切換中文／英文：`F12`、`Ctrl+空白鍵`、單獨點一下 `Ctrl` 鍵，或工具列按鈕。
- 切換全形／半形：`Shift+空白鍵`，或工具列按鈕。

## 內部字典分組（group5～group11）

查詢時依模式套用不同優先順序，主要分組如下：

| 分組 | 內容 |
| --- | --- |
| `group5` | 標準嘸蝦米字根拆碼字典（單字） |
| `group6` | 符號／簡碼字典（如 `a1` 這種「字母＋數字」的兩碼查詢） |
| `group7` | 內建詞庫（詞語，拆碼結尾通常加 `'`），也是使用者匯入 `.box`／`.txt` 後新增詞條的地方 |
| `group8` | 同音字反查表，只在同音字模式**第二階段**（選出底字之後）使用 |
| `group9` | 打繁出簡對照表（`,,ct` 模式使用） |
| `group10` | 簡體字對照表（`,,c` 模式使用） |
| `group11` | 日文字對照表（`,,j` 模式使用） |
| `KEY_TO_ZHUYIN` | 標準注音鍵盤對照表：按鍵 → 注音符號／聲調符號，供注音模式（`';`）顯示與合法鍵判斷使用 |

一般模式查詢優先序：`group5` → `group7` → `group6`，並自動去重。

## 技術架構

- **單一 HTML 檔**：CSS、JavaScript 全部內嵌，無需建置流程，也不依賴任何外部 CDN 或套件。
- 同一套組字核心（`processComposition` 等函式）同時處理**實體鍵盤**（`keydown` 事件）與**滑鼠點擊虛擬鍵盤**，確保兩種操作方式行為完全一致。
- 內部以一個狀態物件（`state`）追蹤目前的字根、候選字、分頁、目前所在模式（一般／快打／同音字／萬用字元／注音／台／簡／日／詞組合）等，所有按鍵處理都是對這個狀態物件做讀寫，再統一呼叫 `renderBar()` 重繪畫面（浮動視窗、印章、虛擬鍵盤標籤等）。

## 已知限制

- 匯入的自訂詞庫只存在記憶體中，重新整理頁面即遺失，需重新匯入。
- 內建範例詞庫與同音字反查表資料量有限，僅供示範，實際使用建議自行匯入完整詞庫檔。
- 目前僅提供繁體（含打繁出簡）、簡體、日文三種切換字庫，不包含其他語言。
